# Blink Project 💡

Projet de prise en main d'une carte Arduino Uno avec PlatformIO et VS Code, consistant à piloter le clignotement d'une LED externe via un circuit électronique de base.

---

## 🛠️ Matériel Requis

* **Carte Microcontrôleur :** Arduino Uno (ou compatible)
* **Plaque d'essai (Breadboard)**
* **LED :** 1x LED
* **Résistance :** 1x Résistance 220 Ω
* **Câbles de connexion :** 2x Câbles Dupont (Mâle/Mâle)
* **Câble USB** pour l'alimentation et la programmation

---

## 🔌 Circuit & Câblage

Le montage respecte la configuration suivante :

1. **Anode (Patte longue de la LED) :** Connectée à la **Broche Numérique 13** de l'Arduino via une résistance de 220 Ω.
2. **Cathode (Patte courte de la LED) :** Connectée à la broche **GND** (masse) de l'Arduino.

---

## 💻 Environnement de Développement

* **IDE :** Visual Studio Code
* **Extension :** PlatformIO IDE
* **Framework :** Arduino
